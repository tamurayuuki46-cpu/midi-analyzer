# MIDI Analyzer 初心者モード

Version: v0.17-dev
更新日: 2026-10-14

## 目的

MIDIを読み込んだ直後に、専門用語や大量の数値を追わなくても「このMIDIの主な特徴」「良いところ」「改善候補」「次に試すこと」を理解できる入口を提供する。

初心者モードは既存Analyzerの解析結果を初心者向けの言葉へ要約する表示レイヤーであり、元MIDI・Normalized Song・候補順位・SongProject・IndexedDB Schemaを変更しない。

## 操作フロー

1. MIDIを読み込む。
2. 初心者モードが最初に表示される。
3. Key / 音域 / 音の動き / リズム / 反復の5項目を確認する。
4. 「良いところ」と「改善するとよいところ」を確認する。
5. 「次に試すこと」を最大3件だけ確認する。
6. 必要な場合だけ「詳細モード」へ切り替え、従来の13解析タブを使う。

表示モードは `localStorage` の `midi-analyzer.analysis-mode.v1` に端末内保存する。保存できない環境では初心者モードを初期値として動作する。

## 要約ルール

- Key: 既存Key Analyzerの第1候補を表示する。確率や正解とは扱わない。
- 音域: 7半音以下を「せまめ」、8〜16半音を「ちょうど」、17半音以上を「広め」の目安として表示する。
- 音の動き: Melody Analyzerの平均跳躍を「なめらか / ほどよく動く / ジャンプが多め」に言い換える。
- リズム: 拍頭以外の発音比率から「まっすぐ / ほどよく変化 / 細かく動く」を表示する。
- 反復: 既存Motif Analyzerの4音Motif候補を使い「まとまりあり / 反復少なめ / まだ判定しにくい」を表示する。

これらは作曲品質・人気・正解を採点する指標ではない。改善候補も「変更すべき命令」ではなく、元案と比較するための試行候補として表示する。

## プライバシー

初心者モードの分析は端末内で完結する。MIDI、音声、解析結果を外部AIや外部サービスへ自動送信しない。

## 回帰条件

- 既存13解析タブを削除しない。
- 初心者モードから詳細モードへ切り替えて全タブを使用できる。
- 詳細モードから初心者モードへ戻せる。
- 360 / 390 / 430pxで横スクロールを発生させない。
- SongProject / MIDI保存 / Export / Key変更 / Library導線を維持する。
- Console errorを発生させない。
